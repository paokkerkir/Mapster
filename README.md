# Mapster 1.4.0 for WoW 3.3.5 - WotLK

Mapster is a very simple world map enhacement addon, which was designed to work in conjunction with all other map addons out there. The idea to create Mapster originated from pure lack of a simplistic addon that only modifies the world map, without adding a full scale feature set.


This is a fork based originally on the [1.3.9 WOTLK client 3.3.5 version](https://warperia.com/addon-wotlk/mapster/), updated for current addon compatibility.


# Installation

1. Download the Repo
2. Unzip the Download
3. Rename Mapster-main folder to Mapster
4. Drag the Mapster folder to your Addons folder.
